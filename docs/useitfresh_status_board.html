01 Your list

Four jobs. Two unblock me, two are housekeeping. Nothing here needs code — they are all clicks in FlutterFlow or Supabase.

The fridge is skipped when signed out 1 min

The app's front door still points at the old welcome screen. This is the single click that makes the fridge the first thing a new user sees.

  1. Open the project in FlutterFlow
  2. Left sidebar, bottom → Settings (the gear)
  3. Under App Settings → Authentication
  4. Find Entry Page (sometimes labelled Initial Page)
  5. Change it from WelcomePage to SignInPage
  6. Save
Why I can't do this one: the setting lives in the auth config, and writing Supabase auth config from code can clobber your OAuth connection — they share a protobuf field. I tried the two safe routes (changing the page's route, then setInitialPage); both pushed cleanly and neither moved it. The UI toggle is zero risk.

Re-sync the database schema 1 min

I added three columns to the food view (a friendly status label, a plain-English detail line, an icon name). FlutterFlow's copy of your database is from before that, so the inventory screen won't compile until it catches up.

  1. In FlutterFlow → Settings
  2. Integrations → Supabase
  3. Click Get Schema
  4. Wait for it to say 15 tables imported (not 14)
The inventory screen is already written and waiting in dsl/_pending_i4_inventory.dart.txt — one push after this.

Rotate the database password 2 min

It was pasted into a chat transcript once. Treat any credential that lands in a transcript as burned. Nothing in the app uses it, so rotating breaks nothing.

  1. Open Supabase → your project
  2. Project Settings → Database
  3. Reset database password
  4. Save the new one in your password manager. You do not need to tell me.

Point password-reset emails at the right page 2 min

Someone who resets their password gets an email, and that link currently lands on the wrong screen. Change-password from inside Profile already works — this is only the email route.

  1. Supabase → Authentication
  2. URL Configuration
  3. Under Redirect URLs, add your site URL followed by /update-password
  4. Save
