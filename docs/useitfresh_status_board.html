02 Sign in with Google and Apple

Not urgent — email sign-in works today. But these two go together: if you offer Google on iPhone, Apple's review rules require Apple sign-in too. Treat them as one job.

Google ~20 min

Do the Web client only. Android needs a SHA-1 fingerprint from a signing keystore that does not exist yet, and iOS needs the app registered with Apple first — both come later, at release. If you are sitting on the Android form now, press the back arrow.

  1. Google Cloud Console → project UseItFresh → Google Auth Platform → Clients → + Create client
  2. If it asks for Audience first, choose External. Internal only works for Google Workspace organisation accounts.
  3. Application type → Web application
  4. Name → UseItFresh Web
  5. Authorised JavaScript origins → + ADD URI twice:
    http://localhost:8080
    https://ltdvxdizjrkgwldbmbbf.supabase.co
  6. Authorised redirect URIs → + ADD URI once:
    https://ltdvxdizjrkgwldbmbbf.supabase.co/auth/v1/callback
  7. Create. A box appears with a Client ID and a Client secret — copy both now.
  8. Supabase → Authentication → Sign In / Providers → Google → toggle Enable → paste the Client ID and Client secret → Save
At release we come back and add an Android client (package com.mycompany.useitfresh plus the keystore SHA-1) and an iOS client (bundle com.mycompany.useitfresh). Neither is needed to test.

Apple ~30 min

  1. Apple Developer → Certificates, Identifiers & Profiles
  2. On your App ID, enable the Sign in with Apple capability
  3. Create a Services ID — this is what the web and Supabase use
  4. Create a Key with Sign in with Apple enabled. It downloads a .p8 file once — save it somewhere safe, you cannot download it again
  5. Note your Team ID and the Key ID
  6. Supabase → Providers → Apple: paste the Services ID, Team ID, Key ID and the contents of the .p8 file
You already have the hard part. Google and Apple sign-in both work on Spot a Paw, on the same Supabase setup — so this is repeating a process you have done, not solving it fresh.

Which of these are secret

The left column is safe to paste anywhere, including to me. The right column goes into Supabase and nowhere else — never into the app, a message, or the repo.
